# Vampirism: Witch v0.1.0

Mod project for **Minecraft 26.1.2 / NeoForge / Java 25**.

## This test version
- Adds the **Vampirism: Witch** creative inventory tab.
- Adds **Witch Hat** item with pixel-art hat texture, used as tab icon.
- Requires Vampirism installed at runtime.

This is **not yet** the faction leveling / P-menu interface.
The hat is an ordinary item, not equippable.

## Download a built JAR
Open **Actions** > **Build Vampirism Witch JAR** > latest successful run > **Artifacts**.
Extract the downloaded ZIP and copy its `.jar` into your Minecraft `mods` folder.

If a build fails, inspect the logs in Actions; no valid JAR will be produced.
