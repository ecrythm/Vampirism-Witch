# Vampirism: Witch v0.4.2

Minecraft 26.1.2 / NeoForge / Vampirism / FactionAPI.

## Fixes
- Cauldron walls no longer overlap; campfire is always unlit visually, even when the cauldron is heating.
- No flame appears inside the bowl; blue water at levels 1–3 uses an opaque texture to prevent overlapping translucent layers.
- Heated water shows occasional bubble-pop particles above the surface.
- First skill renamed to **Becoming a Witch**, with its existing description unchanged.
- Pixel-art Witch Hat icon is used both for the skill and the Witch advancement tab and its first achievement.
- New advancements tab named **Witch**, with a separate first advancement: **This is only the begging!** / **Become a witch**.
- Normal brewing interactions and faction rank commands unchanged.

### Download
GitHub Actions > latest successful build > Vampirism-Witch-0.4.2. Remove the previous JAR before installing.
